# osu! Chaos Remote

[English Version](README.md)

Пользовательский Fun-мод для **osu!lazer**, который позволяет второму человеку (например, чату стримера или другу) интерактивно вмешиваться в игровой процесс в реальном времени. Мод связывается с панелью управления на Python через TCP-сокет, что позволяет динамически контролировать сложность игры и интерфейс.

## Особенности (Дебаффы)

- **Ветер (Гравитация)**: Сдвигает ноты по экрану с настраиваемой силой и направлением.
- **Магнит**: Динамически отталкивает ноты от курсора игрока.
- **Землетрясение**: Трясет всё игровое поле и интерфейс.
- **Светошумовая (Flashbang)**: Временно ослепляет игрока белой вспышкой на весь экран.
- **Hidden (Слепота)**: Позволяет включать и выключать стандартный мод "Hidden" (невидимые подходные круги) прямо во время игры.
- **Блэкаут (Остановка времени)**: Полностью останавливает все объекты на 5 секунд, пока песня продолжает играть.
- **Поцелуй**: Создает огромный отвлекающий визуальный эффект прямо по центру экрана.
- **Фейковый промах**: Воспроизводит звук и анимацию промаха, чтобы сбить игрока с толку.
- **Искажение поля и HUD**: Позволяет сжимать, растягивать или сплющивать игровое поле и интерфейс по осям X и Y.
- **Отзеркаливание**: Отражает игровое поле или интерфейс по горизонтали и вертикали.

## Установка

### 1. Панель управления (Python)
Для работы панели управления требуется Python 3. Никаких сторонних библиотек не требуется, так как используются встроенные модули `tkinter` для графического интерфейса и `socket` для сети.

1. Перейдите в директорию `ControlPanel/`.
2. Запустите приложение:
```cmd
python main.py
```

### 2. Мод для osu! (C#)
Поскольку osu!lazer в данный момент не поддерживает загрузку сторонних модов как внешних плагинов, этот мод необходимо скомпилировать напрямую в исходный код игры.

1. Склонируйте официальный [исходный код osu!](https://github.com/ppy/osu).
2. Скопируйте файл `OsuModChaos.cs` из папки `OsuMod/` этого репозитория в `osu/osu.Game.Rulesets.Osu/Mods/`.
3. Откройте `osu.Game.Rulesets.Osu/OsuRuleset.cs` и зарегистрируйте мод, добавив `new OsuModChaos()` в метод `GetModsFor()` (например, в секцию `ModType.Fun` или `ModType.Conversion`).
4. Соберите и запустите проект `osu.Desktop`.

## Как это работает
Когда мод выбран и активен в игре, он запускает локальный TCP-сервер на порту `2826`. Панель управления на Python подключается к `127.0.0.1:2826` и отправляет текстовые команды (например, `WIND_ON`, `EARTHQUAKE_STRENGTH:1.5`, `FLASHBANG`). Мод парсит входящие команды и в реальном времени переопределяет трансформации объектов `DrawableHitObject` и свойства игрового поля.
