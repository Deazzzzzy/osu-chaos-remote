# osu! Chaos Remote

[English Version](README.md)

Пользовательский Fun-мод для **osu!lazer**, который позволяет второму человеку (например, чату стримера, другу или донатерам) интерактивно вмешиваться в игровой процесс в реальном времени. Мод связывается с панелью управления на Python через TCP-сокет, позволяя динамически управлять сложностью игры, курсором, нотами, звуком и вызывать внезапные события.

---

## 🎮 Возможности и дебаффы

### 1. Курсор и управление
- **Аппаратный инпут-лаг**: Реальная задержка движения курсора (буферизация ввода в миллисекундах).
- **Невидимый курсор**: Полное скрытие курсора игрока во время игры.
- **Шизофрения (Фейковые курсоры)**: Спавн ложных копий курсора со следами (зеркальные, отстающие, рой).
- **Размер курсора**: Масштабирование курсора от крошечной точки (0.1x) до гигантского круга (5.0x).
- **Инверсия управления**: Зеркальный переворот координат настоящего курсора по осям X и Y.
- **Залипание клавиш (Key Jam)**: Блокировка кликов клавиш K1 (Left) и/или K2 (Right) для принудительного сингл-тапа.

### 2. Физика поля и ноты
- **Ветер (Гравитация)**: Сдувание нот по экрану с настраиваемой силой и направлением (0°–360°).
- **Магнит**: Отталкивание нот от курсора игрока.
- **Чёрная дыра**: Сингулярность в центре экрана (256, 192) с вращающимся аккреционным диском, втягивающая ноты к центру.
- **Хамелеон**: Подмена цветов всех нот, слайдеров и подходных кругов (Чёрный стелс, Радужное диско, Монохром).

### 3. Искажения экрана и звук
- **Рассинхрон звука (Audio Desync)**: Смещение аудиодорожки относительно нот вперед или назад (-300ms до +300ms).
- **Землетрясение**: Динамическая тряска всего игрового поля и HUD.
- **Искажение масштаба**: Сжатие и растяжение игрового поля и интерфейса по осям X и Y.
- **Отзеркаливание**: Переворот поля или интерфейса по горизонтали и вертикали.

### 4. Внезапные события и троллинг
- **Разряд батареи 5% 🔋**: Тост Windows в правом нижнем углу с предупреждением и системным звуком.
- **Входящий звонок Discord 📞**: Окно вызова с логотипом Discord, аватаром "Best Friend", вибро-покачиванием и кнопками.
- **Синий экран смерти (BSOD) 💻**: Полноэкранный Windows BSOD (`CRITICAL_PROCESS_DIED`, `osu!.exe`) со звуком критической ошибки на 3 секунды.
- **Угроза Windows Defender 🛡️**: Системное уведомление защиты с сообщением о трояне.
- **Блэкаут (Freeze)**: Остановка времени для нот на 5 секунд при продолжающейся музыке.
- **Flashbang 💥**: Ослепляющая белая вспышка на весь экран с плавным затуханием.
- **Поцелуй 💋** и **Фейковый промах ❌**: Отвлекающие анимации и звуки сбития комбо.
- **Радар галлюцинаций**: Интерактивная миникарта в панели управления для спавна фейковых нот по клику.

## 🚀 Установка и запуск

### 1. Панель управления (Python)
Требуется Python 3. Используются стандартные встроенные библиотеки `tkinter` и `socket` (установка сторонних пакетов не требуется).

```powershell
cd ControlPanel
python main.py
```

### 2. Мод для osu! (C#)
1. Склонируйте исходный код [osu!lazer](https://github.com/ppy/osu).
2. Скопируйте файлы мода из папки `OsuMod/` в директорию `osu/osu.Game.Rulesets.Osu/Mods/`:
   - `OsuModChaos.cs`
   - `TrollOverlay.cs`
   - `FakeCursorOverlay.cs`
   - `HiddenCursorOverlay.cs`
   - `HallucinationOverlay.cs`
   - `call_calling.mp3`
3. Зарегистрируйте мод в `osu.Game.Rulesets.Osu/OsuRuleset.cs` внутри метода `GetModsFor()`:
   ```csharp
   new OsuModChaos(),
   ```
4. Соберите и запустите `osu.Desktop`:
   ```powershell
   dotnet run --project osu.Desktop/osu.Desktop.csproj -c Debug
   ```

## 📡 Сетевое взаимодействие
Мод слушает TCP-порт **9000** (по умолчанию `127.0.0.1:9000`). Панель управления отправляет текстовые команды (например, `TROLL:BSOD`, `BLACK_HOLE_ON`, `INPUT_LAG:150`), а клиент osu! мгновенно применяет их в активной игровой сессии.
